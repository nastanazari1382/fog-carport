# Carport Fog

Semesterprojekt på Datamatiker 2. semester, Cphbusiness Lyngby, efterår 2026.

Vi bygger et website til Johannes Fog, hvor en kunde kan bestille en carport efter egne mål.
Kunden ser en tegning af carporten, og en sælger sender et tilbud.
Når kunden har betalt, kan han se styklisten.
